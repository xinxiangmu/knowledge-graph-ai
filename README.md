## 📌 项目简介 / Overview

**中文版：** Knowledge Graph AI 是一款 Obsidian 插件，通过 AI 驱动的实体提取和关系映射，将你的笔记转化为结构化的知识网络。

**English:** Knowledge Graph AI is an Obsidian plugin that transforms your notes into a structured knowledge network using AI-powered entity extraction and relationship mapping.

---

## ✨ 主要功能 / Key Features

- 🧠 **AI 文档解析 / AI Document Parsing**: 智能提取实体和关系
- 🗺️ **交互式知识图谱 / Interactive Graph**: 可视化展示知识连接
- 🔗 **智能实体管理 / Smart Entity Management**: 自动融合重复实体
- 📅 **时间轴视图 / Timeline View**: 按时间顺序展示知识节点
- 🧩 **层级视图 / Hierarchy View**: 树状结构展示知识分类
- 🔍 **智能搜索 / Smart Search**: 多维度过滤和搜索实体

## 🚀 快速开始 / Get Started

1. 在 Obsidian 社区插件中搜索 **Knowledge Graph AI** / Search for **Knowledge Graph AI** in Obsidian community plugins
2. 安装并启用插件 / Install and enable the plugin
3. 点击侧边栏的 🧠 图标打开面板 / Click the 🧠 icon in the sidebar to open the panel
4. 配置 AI 模型 / Configure AI model
5. 上传文档开始分析 / Upload documents to start analysis

---

## 🔒 隐私保护 / Privacy

- 🇨🇳 所有知识图谱数据存储在你的 Obsidian 库中，不收集任何笔记内容
- 🇬🇧 All knowledge graph data stored in your Obsidian vault. No note content collected.
